# Prolog — Error Tracking & Monitoring Landing Page

A pixel-perfect, responsive landing page converted from a Figma design. Built with plain HTML5 and CSS3 — no frameworks or dependencies required.

## 🖥️ Live Preview

Open `index.html` directly in any modern browser to view the page.

## 📁 Project Structure

```
figma/
├── index.html          # Main HTML file
├── style.css           # All styles (layout, typography, responsive)
└── photo/              # Image assets
    ├── Logo.png                    # Prolog brand logo
    ├── Logo1.png – Logo5.png       # Partner company logos
    └── Macbook Pro 16 mockup.png   # Hero product screenshot
```

## ✨ Features

- **Sticky navigation bar** with logo, nav links, and a CTA button
- **Hero section** with headline, description, and dual call-to-action buttons
- **Product screenshot** displayed on a Macbook Pro mockup
- **Partners banner** showcasing 5 partner company logos
- **Fully responsive** — adapts gracefully to mobile screens (≤ 768 px)
- **Smooth scrolling** enabled site-wide
- Uses the [Inter](https://fonts.google.com/specimen/Inter) typeface via Google Fonts

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Bishalkunwar11/figma.git
   ```
2. **Open the page**
   ```bash
   cd figma
   open index.html        # macOS
   # or
   start index.html       # Windows
   # or simply drag index.html into your browser
   ```

No build step, package manager, or server is needed.
